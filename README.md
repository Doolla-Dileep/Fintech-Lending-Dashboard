# Fintech-Lending-Dashboard
An end-to-end fintech data pipeline using MySQL &amp; Power BI to process 32K+ credit records. Deployed advanced SQL data wrangling to clean anomalies and engineered an interactive dark-themed dashboard mapping a $17M+ portfolio, isolating high-risk default clusters using KPI trackers, risk treemaps, and dynamic cascading filters.

## Project Objective
To develop an interactive Power BI dashboard that analyzes lending performance, loan applications, funding, interest rates, loan grades, and borrower characteristics to generate actionable business insights and support data-driven decision-making.

## Key Insights
Loan Grade Risk 
Default rates vary significantly across loan grades, with mid‑tier grades showing higher risk  compared  to premium grades.

Interest Rate Patterns 
Average interest rates decrease steadily from high‑risk grades to safer ones, helping lenders balance profitability with borrower reliability.

Borrower Demographics 
Renters form the largest borrower segment, followed by mortgage holders, indicating strong demand among urban, non‑homeowning populations.

Loan Intent Trends 
Education and debt consolidation dominate funded amounts, showing where lending demand is most concentrated.

Application Dynamics
Application trends reveal fluctuations over time, with interactive filters enabling deeper analysis by year, ownership type, and loan status


## conclusion
Overall, this dashboard serves as a strategic tool for recruiters, lenders, and business leaders to evaluate loan portfolio performance, identify borrower risk segments, and track lending trends.
By presenting clear KPIs and interactive visuals, it enables informed decision‑making, supports risk management, and highlights opportunities for sustainable growth in the lending market.
